🎯 Objetivo
Este projeto consiste em um dashboard interativo desenvolvido através do Antigravity com Gemini, Python (FastAPI) e React (Next.js), focado em governança, monitoramento de riscos e rastreamento de dados (GRC).

Ele funciona como uma central de controle para identificar anomalias e garantir a conformidade em interações sistêmicas. A construção desta ferramenta exigiu a estruturação de indicadores (KPIs), a criação de painéis de monitoramento em tempo real e a aplicação de análise de dados para a mitigação de riscos operacionais.
