# AI Trust & Security Auditor

## 🎯 Objetivo

Dashboard interativo desenvolvido através do **Antigravity** com **Gemini**, **Python (FastAPI)** e **React (Next.js)** focado em governança, monitoramento de riscos e rastreamento de dados (GRC). 

O projeto funciona como uma central de controle para identificar anomalias e garantir a conformidade em interações sistêmicas. A construção desta ferramenta desenvolveu minha capacidade de estruturar indicadores (KPIs), criar painéis de monitoramento em tempo real e aplicar análise de dados para a mitigação de riscos operacionais.
