# AI Trust & Security Auditor

## 🎯 Objective

Interactive dashboard developed using **Antigravity** with **Gemini**, **Python (FastAPI)**, and **React (Next.js)**, focused on governance, risk monitoring, and data tracking (GRC). 

The project functions as a control center to identify anomalies and ensure compliance in system interactions. Building this tool developed my ability to structure indicators (KPIs), create real-time monitoring panels, and apply data analysis for operational risk mitigation.
